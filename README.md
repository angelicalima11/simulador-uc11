# Simulador UC11: Projeto Aprendizagem – Plano de Desenvolvimento Pessoal e Profissional

Idealizado pela instrutora Maria Angélica de Lima - Senac/Jataí-GO, desenvolvido por Claude.ai e Canva.

Simulador individual em fases para o curso de Aprendizagem Profissional em Comércio de Bens, Serviços e Turismo (PCN 2023, UC11). O aluno decide situações da personagem Lia, libera fases com pontuação mínima e recebe um relatório automático com indicadores, habilidades, atitudes/valores e conceito final.

Abra o arquivo `index.html` no navegador ou use o GitHub Pages deste repositório.
